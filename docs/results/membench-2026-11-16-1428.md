# MemoLang runtime benchmark, 2026-11-16 14:28

Written by `MemoLangTests membench --save`. Do not edit by hand.

- Conditions: 11th Gen Intel(R) Core(TM) i7-1185G7 @ 3.00GHz, MSVC 19.51.36260, Release, median of 5 runs
- Matrices: 256x256 f32 (0.25 MiB each), CPU matrix runtime
- MemoLang base: matrices freed at the end of their scope (like C++)
- MemoLang destructive: matrices freed the moment they are consumed
- C++ plain: native code, freed at the end of scope
- C++ hand-freed: native code, each matrix freed by hand after its last use
- All four versions of each workload returned the same result

| Workload | MemoLang base | MemoLang destructive | C++ plain | C++ hand-freed |
|---|---|---|---|---|
